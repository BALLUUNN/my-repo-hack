# Вклад Vova Boldakov

## Зоны работы

- **Дизайн:** участвовал в разработке дизайна интерфейса и пользовательских сценариев.
- **Бизнес-логика:** разрабатывал правила ежедневных заданий, питомца, листьев, уровней, наград, сундуков и обработки внешних событий.
- **API:** разрабатывал и подключал endpoint-ы для заданий, питомца, сундуков и internal events; настраивал маршрутизацию и модели запросов/ответов.
- **Ежедневные задания:** реализовал сервис прогресса, определения заданий, назначение задач, запись событий и получение наград.
- **Питомец:** реализовал API питомца, изменение имени, начисление листьев, уровни, level rewards и WebSocket-обновления.
- **Сундуки:** реализовал транзакционное открытие сундука, списание листьев, каталог наград и проверки.
- **Events:** участвовал в реализации обработки внешних событий и internal API.
- **Тестирование:** написал unit-, интеграционные и black-box тесты для заданий, питомца и сундуков.
- **CI:** настроил базовый GitHub Actions CI, проверки линтера и автоматический запуск тестов.
- **Конфигурация:** подготовил YAML-конфигурации наград, лидерборда и заданий.
